# Security Policy

**Please do not report security vulnerabilities through public GitHub issues or pull
requests.**

Report privately through GitHub's "Report a vulnerability" button on this repository's
Security tab, or by email to **security@maxsys.org**.

Please include what you found, how to reproduce it, and the plugin and WordPress
versions. We aim to acknowledge a report within 7 days, and we will credit you when a
fix is released if you would like that.

The latest released version is the supported one.
